Publier le quiz

  1. Clique sur « Télécharger le fichier ».
  2. Sur GitHub, ouvre le dossier quiz du dépôt, puis Add file > Upload files. Dépose le fichier (il remplace l’ancien s’il porte le même nom) et valide avec Commit changes.
  3. Après une minute ou deux, le quiz est accessible au lien ci-dessus.

Ton travail est gardé automatiquement dans ce navigateur. « Tester » ouvre le quiz tel qu’il est ici, sans le publier.
